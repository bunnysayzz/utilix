# Roadmap (High-Level, Subject to Change)

This is a non-binding outline of areas we’re exploring. Priorities may change based on feedback.

## Under Consideration
- Snippets improvements (search, tagging)
- Clipboard history refinements
- Additional quick actions in menu bar
- Performance and memory use tuning

## Nice-to-Have Ideas
- More customization for Desktop Switch glow
- Optional export/import for settings/snippets (local only)
- Additional network utilities (e.g., simple ping UI)
