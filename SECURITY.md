# Security Policy

## Supported Versions
Please report issues against the latest release available on the Releases page.

## Reporting a Vulnerability
If you believe you’ve found a security vulnerability in Utilix:

1. Do not create a public issue.
2. Email a private report to `stfuazzo@gmail.com` with:
   - A detailed description of the issue
   - Steps to reproduce
   - Affected macOS version and Utilix version
   - Any proof‑of‑concept or screenshots
3. You’ll receive an acknowledgment within 5 business days.

## Disclosure
We will investigate and, if confirmed, fix the issue in a subsequent release. We may credit reporters in release notes if you consent.
