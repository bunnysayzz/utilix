# Permissions

Nothing is asked at launch. Each permission appears the first time its
feature runs; after that, manage everything live in
Settings → Permissions (status re-reads while the tab is open, with deep
links to each System Settings pane).

## Accessibility
- Powers Desktop Switch, Window Snap, snippet expansion, global shortcuts,
  Auto Typing, and automation features.
- Asked once, on first use of any of these (a second use never re-prompts —
  denied features explain inline with a Settings link instead).
- If features stop working after an app update: toggle Utilix OFF and ON
  in System Settings, then relaunch Utilix.

## Screen Recording
- Powers Mac Vision OCR (capturing text from screen) and GIF Recorder.
- Asked on first capture. **Important:** after granting, quit and reopen
  Utilix once — macOS only attaches the grant to the next process the app
  launches, so captures fail until you restart.
- Non-English text? Turn on **All languages** in the Mac Vision pane.

## Calendars (Optional)
- Powers Calendar Meetings (upcoming events with one-click join links).
- Asked on first calendar open. Background refreshes never prompt.
- Public holidays need no permission at all.

## Full Disk Access (Optional)
- Helps Trash, file tools, and browser data work reliably.
- macOS offers no prompt for this one: use the in-app **Fix** button
  (creates the Settings row), then flip the toggle manually.

## Notifications
- Meeting warnings, Pomodoro timers, completion signals. Asked on first
  delivery; denied sends stay silent by design.

If a permission looks enabled but features don't work: toggle it OFF and
ON in System Settings, relaunch Utilix, and re-check from
Preferences → Permissions. The app never needs Camera, Microphone, or
Location — any such prompt would be a bug; report it.
