# Permissions

Utilix requests certain macOS permissions for features to function properly.

## Accessibility
- Required for Desktop Switch, Window Snap, global shortcuts, Auto Typing, and automation features.
- Open System Settings → Privacy & Security → Accessibility and enable Utilix.
- In the app, go to Preferences → Permissions to open the correct settings page.

## Screen Recording
- Required for Mac Vision OCR (capturing text from screen) and GIF Recorder.
- Open System Settings → Privacy & Security → Screen Recording and enable Utilix.

## Calendars (Optional)
- Required for Calendar Meetings (upcoming events with one-click join links).
- Open System Settings → Privacy & Security → Calendars and enable Utilix.

## Full Disk Access (Optional)
- Helps some file utilities work more reliably.
- Open System Settings → Privacy & Security → Full Disk Access and enable Utilix.

If a permission looks enabled but features don’t work, toggle it off and on again, then restart Utilix.
