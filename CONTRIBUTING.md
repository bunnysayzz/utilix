# Contributing to Utilix (Community Repo)

Thanks for your interest in contributing! This repository contains community documentation, issue templates, and binary releases of Utilix. The application source code is closed‑source and not part of this repo.

## How You Can Help
- Report bugs using the provided issue templates
- Request features and improvements
- Improve documentation (README, usage tips, FAQs)
- Help triage and reproduce reported issues

## Scope of Pull Requests
- Documentation only (Markdown, images, GitHub workflows/templates)
- No application source code
- Do not submit reverse‑engineered or decompiled code

## Issue Reports
- Use the Bug Report template and fill in all fields
- Include macOS version, chip (Intel/Apple Silicon), and Utilix version
- Provide steps to reproduce and expected vs actual behavior
- Add screenshots or logs if helpful

## Feature Requests
- Use the Feature Request template
- Describe the problem, the proposed solution, and alternatives considered

## Style
- Keep docs concise, user‑focused, and accessible
- Prefer American English spelling
- Use Markdown headings and lists for scannability

## Security
- Please do not disclose vulnerabilities publicly. See `SECURITY.md` for reporting instructions.

## Code of Conduct
- By participating, you agree to follow our `CODE_OF_CONDUCT.md`.
