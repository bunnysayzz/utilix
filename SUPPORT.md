# Support

If you need help with Utilix:

## Self-Help
- Read `docs/getting-started.md` for installation and setup
- Check `docs/permissions.md` and `docs/troubleshooting.md`
- Review `docs/faq.md`

## Report an Issue
- Use the Bug Report template in the Issues tab
- Include macOS version, Intel/Apple Silicon, and Utilix version
- Provide steps to reproduce and screenshots (if applicable)

## Feature Requests
- Open a Feature Request issue explaining the problem and desired outcome

## Security
- Do not open public issues for vulnerabilities. See `SECURITY.md` for private reporting instructions.
